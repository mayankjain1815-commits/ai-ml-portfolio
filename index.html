Demo mode is a parallel implementation, not a stub.

Every Python project ships a deterministic, rule-based brain that performs the same pipeline the LLM performs — real extraction, real rubric scoring, real retriever math. That is why the whole portfolio runs offline in CI and in a live demo with zero keys. Set GEMINI_API_KEY and the same code upgrades to real model calls with an honest fallback. The two operations projects (07 and 08) use seeded forecast/telemetry streams for the same reason: every number is reproducible. Ask any project what it would do with a key or a live feed and the answer is architectural, not aspirational.

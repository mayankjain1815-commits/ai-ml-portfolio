# Project overview — what this portfolio is

This is one of six self-contained AI/ML projects, each with its own README,
tests, and demo mode. They are built to be complex enough to impress and
simple enough to explain out loud in two minutes.

Ask Orbit: "read project-overview".

- 01 Orbit — this voice assistant (you are here).
- 02 Crew Engine — multi-agent frameworks on a shared blackboard.
- 03 RAG Studio — retrieval-augmented generation from scratch.
- 04 Model Watch — drift detection and model monitoring.
- 05 Skill Forge — an agent skill system with a SKILL.md format.
- 06 GH Activity Forge — a GitHub contribution-graph generator.

Every project runs offline in demo mode and upgrades to real LLM calls when
GEMINI_API_KEY is set. No langchain, no streamlit — the mechanics are rebuilt
by hand so they can be explained (and defended) in an interview.
